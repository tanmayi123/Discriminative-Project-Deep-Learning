The EYE user manual

The EYE (Explainable YOLO Explorer) is our detector's front end. It builds a test image from photos the model never trained on, finds our 73 objects in it, and explains every box in plain sentences. This manual covers every control, every colour and every number on the screen.

Version EYE v3Address 127.0.0.1:7862Default model yolo26s_boostThresholds 0.10 grids, 0.35 scenes

1Start and stop

The EYE runs on the laptop that holds the project and its GPU. Nothing is uploaded anywhere; your browser talks to a small server on your own machine.

  1. Open a terminal in the project folder PROJECT - 1\M2 extra. Close anything else using the GPU, such as a training run or a second EYE.
  2. Start the server:python m2_eye_app_v3.py
  3. Your browser opens http://127.0.0.1:7862. If it does not, type the address yourself.
  4. Wait for the intro animation and the status line under the eye to say model ready.
  5. To stop, press Ctrl+C in the terminal, or close it.
VersionStart withAddressUse it for
EYE v3python m2_eye_app_v3.py in M2 extra:7862Everything. The final version.
EYE v2python m2_eye_app_v2.py in M2 extra:7861Fallback with the first improved model.
Originalpython m2_eye_app.py in MILESTONE 2:7860Fallback with the Milestone 2 model only.

Good to know. The first DETECT after starting takes a few seconds because the model loads then. After that, an image takes well under a second.

3Make a test image

There are three ways to get an image into the pupil: Random builds one from the brow settings, Upload takes your own photo, and you can drag a photo onto the page. Random images use only held-out test photos whose boxes were checked by a person, so the EYE can mark every box right or wrong.

Mix

The Mix panel has three rows of choices. If it does not fit, it scrolls.

RowChoiceEffect
SectionsOne chip per section of the object listOnly objects from the selected sections go into grids.
SelectionrandomObjects picked at random, each at most once per grid.
look-alikesWhole look-alike groups placed together (watches, wallets, power banks, rackets, sunglasses and goggles, brush and comb, bottles, projectors, plush toys, notebook and keyboard). The hardest test of naming.
LayoutgridUpright photos in rows and columns.
rotatedThe same grid turned 90°, 180° or 270° (the seed decides which).
scatteredA prepared test scene: photos scattered at any angle on a real background the model has never seen.
cut-outsA prepared test scene: objects cut out of their photos and placed on an unseen background.

Scenes are prepared, not built. Scattered and cut-out images come from the evaluation's own test scenes (104 of each). Grid size, sections and selection do not apply to them; the seed picks which scene you get.

Conditions

Damage the image before detection to test robustness. Conditions apply to any image, uploads included.

ChoiceWhat it does

low-resShrinks and re-enlarges it, losing detail.

allAll four at once: the low-quality test from our report.

Seed

A seed is the number behind a random image. The same seed with the same settings gives exactly the same image, every time and on every laptop.

  • Empty box: every Random gives a new image.
  • Type a number: Random rebuilds that exact image.
  • random: clears the box, so the next Random is a new image.
  • keep last: copies the seed of the image on screen, so you can change one setting and compare.
  • The panel always shows the last seed used. Write good ones down for demos.

Upload and drag and drop

Press Upload or U to pick a photo, or drag an image file anywhere onto the page. While you drag, the eye's outline turns into a moving dashed ring and says drop the image into the eye. Other file types are refused, and if you drop several files, only the first is used. Photos larger than 3,000 px are scaled down first.

Uploads cannot be scored. The EYE has no true boxes for your photo, so it shows what it found but cannot say whether it is right. If the photo's width and height are multiples of 224 px, the EYE treats it as a grid (one-box-per-cell rule and the grid threshold); otherwise it treats it as a scene.

4Model, threshold, detect

Model

The dropdown lists every model whose weights are on this laptop: the Milestone 2 runs and the two improved models. The line under it shows the model's test mAP@0.5 and a label.

LabelMeaning
· selectedThe model chosen on validation for the final results: yolo26s_boost. It is the default.
· M2 pickThe model chosen in Milestone 2: yolo26s_ft2. Switch to it to show the "before".

Threshold

The model gives every box a confidence between 0 and 1. The threshold is the cut-off: boxes below it are dropped. The slider runs from 0.05 to 0.90 in steps of 0.05.

  • Lower finds more objects but lets more wrong boxes through. Higher is stricter but misses more.
  • Every model has validated values, chosen on the validation set. For the selected model they are 0.10 on grids and 0.35 on scenes; most other models use one value for everything.
  • While you leave the slider alone, the EYE switches by itself to the right value for the image on screen. The note under the button says which one it uses, for example validated: grids 0.10 · scenes 0.35 · using grids.
  • Move the slider and your value is kept for every image (the note says set by hand) until you press reset to validated.

One box per cell

On grid images each 224-px cell holds exactly one object, so the EYE keeps only the most confident box per cell. This removes most extra boxes. It is on by default and only acts on grids; scenes instead get the selected model's duplicate rule, which keeps one box where boxes of any name overlap heavily.

Detect

Press the DETECT plate at the bottom of the iris ring, press D, or focus the ring and press Enter. The ring spins while the model works.

5Read the image

Every true object and every kept box ends up with exactly one result. The colours are the same in the pupil, on the ring, in the lists and in every chart.

ResultDrawn asMeaning
correctsolid green boxRight object, and the box overlaps the true box by at least half (IoU 0.50 or more).
box offdashed amber boxRight object, but the box overlaps by less than half.
wrong IDsolid magenta boxThe box is on the object but names a different one. Look-alikes are flagged.
misseddashed cyan box at the true positionNo box for a real object. The reason says whether it was seen below the threshold, seen weakly as something else, or very small.
extradotted grey boxA box that matches no object: a second box, part of an object, background, or an unlabelled thing in the photo.
true boxthin dashed whiteWhere the object really is, as checked by a person.

Each box carries a label with the object ID and its confidence, for example OBJ042 0.97. Hover a box for its name, section, class AP, look-alike group and, if it is an error, the reason. Click a box to select its object everywhere.

The iris ring

After detection, the ring shows one segment per object in the result colours, starting at the left of the DETECT plate and running clockwise. Mostly green is a good image; a cyan or magenta patch tells you there is something to look at in the Results list. Before detection it shows faint ticks; while working, it spins.

Under the eye, the status line says what to do next, for example grid ready · press DETECT or D.

6Read the review panels

Panel 1, Score

  • The big number: objects correct out of all objects, with a bar.
  • Verdict: FULLY CORRECT when every object is found with the right name and a good box; otherwise k/n NAMED CORRECTLY, which counts right names even when the box is off.
  • Counts: box off, wrong ID, missed and extra, then correct per section.
  • Time (top right of the panel): milliseconds for this detection; the first one says incl. model loading.
  • For uploads it shows how many objects were found, since nothing can be judged.

Panel 2, Results

One plain sentence per object, for example OBJ025 was called OBJ046, a look-alike. Switch between errors (default) and all.

  • Click a line: the pupil zooms onto that object and Inspect shows it. Click again, or press Esc, to zoom out.
  • Press +: the full record of the object.
Field in +Meaning
result, reasonThe verdict and why.
true object, predictedWhat it is and what the model said, with names.
section, look-alike groupWhere it sits in the object list and its look-alikes, if any.
class AP (test)How well the model handles this object in general, from the Milestone 2 test set (1.0 is perfect).
confidenceHow sure the model was about its box.
IoU with true boxOverlap between its box and the true box, 0 to 1.
predicted box, true boxPixel corners, left-top to right-bottom.

Panel 3, Inspect

Shows the selected object cut from the image next to training photos of the class the model predicted and, for errors, of the true class. That is how you see why a watch was mistaken for another watch. Step through all objects with ‹ ›; the enlarge button makes it bigger.

Panel 4, Threshold sweep

What would have happened at every threshold from 0.05 to 0.90 on this same image, without detecting again. Four lines: correct, missed (dashed), extra (dashed) and wrong ID. The dashed vertical line is the current threshold.

How to use it. If the missed line drops sharply just left of the current threshold, a slightly lower threshold would find those objects. If the extra line climbs there, it would also add wrong boxes.

Panel 4, Box tightness

Switch the panel's tab to tightness. One dot per object the model boxed: across is the IoU with the true box (further right is tighter), up is the confidence. Faint lines mark 0.50, 0.75 and 0.95. The footer counts correct objects past each line and gives the median IoU, for example IoU ≥0.50 24/25 · ≥0.75 21/25 · ≥0.95 7/25 · median 0.89.

This is mAP@0.5:0.95 on one image: a box counts as correct from 0.50, but the stricter metric also asks for 0.55 up to 0.95. Few boxes pass 0.95 because even the true boxes are only about 0.97 exact. Enlarge the panel for a big version with an explanation.

7Large view

Click the pupil to open the image full screen. Along the top you can change the grid size, seed, model and threshold, then press Random or Detect without leaving the view. On the side: the colour legend (hover each entry for its definition), a short summary, the object list with all / errors, and download buttons. Click an object to highlight it. Esc closes the view.

8Stress test

One image can be lucky or unlucky. The stress test runs many random grids with the current brow settings (grid size, sections, selection, conditions, model, threshold) and reports the totals.

  1. Set up the brow, then press Stress in the left dock.
  2. Choose 10 to 300 grids with the slider (100 by default) and press Run. A bar shows progress.
OutputMeaning
objects correctShare of all objects across all grids that were correct.
fully correct gridsShare of grids with no error at all, with a 95% confidence interval.
named correctlyShare with the right name, box off included, plus the time per grid.
totals lineNumber and size of grids, settings, and counts of box off, wrong ID, missed, extra.
three tablesObjects most often missed or wrong, the most common confusions (A called B), and the failure reasons.

Repeatable by design. Grids use seeds 1000, 1001, 1002 and so on, so the same settings give the same result. The stress test always builds grids; layouts do not apply.

12Words you will see

WordPlain meaning
IoUIntersection over Union: the overlap of two boxes divided by their combined area. 1.0 is a perfect fit, 0.5 is "roughly on it".
ConfidenceHow sure the model is about one box, 0 to 1.
ThresholdThe confidence below which boxes are dropped.
ValidatedChosen on the validation set, never on the test sets.
RecallShare of real objects the model found correctly.
PrecisionShare of the model's boxes that are correct.
mAP@0.5Average precision over all 73 objects, a box counting from IoU 0.50: "found and named?"
mAP@0.5:0.95The same at ten IoU cut-offs from 0.50 to 0.95: "found, named and tightly boxed?"
Class APThat score for one object only.
Look-alike groupObjects that look alike, such as our three watches. Errors between them are flagged.
Held-out test photoA photo the model never saw in training or validation.
SceneA scattered or cut-out image, as opposed to a grid.

13Troubleshooting

You seeDo this
The page does not openCheck the terminal for errors. If the port is busy, an older copy is running: close its terminal and start again.
The first DETECT is slowNormal: the model loads then. Later detections are fast.
Every detection is slowSomething else is using the GPU, often a second EYE or a training run. Close it.
No scattered scenes yetThe scene test sets are missing from M2 extra; the grid layouts still work.
An upload shows no scoreExpected: uploads have no true boxes.
Nothing detected on an uploadTry a lower threshold, or a photo where the object is upright and fills more of the frame.
Look-alikes refuses a big gridThere are fewer look-alike objects in your sections than cells; pick a smaller grid or more sections.
Hard to read on a projectorZoom the browser to 125–150%, try the light theme, and turn on Calm while you talk.
